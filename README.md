# 🚀 МЭШ.Импульс

Легковесный Telegram-бот для быстрого доступа к школьному расписанию
и академическим задолженностям. Создан как альтернатива тяжёлому
графическому интерфейсу официальных приложений в условиях
нестабильной школьной сети.

> 🏆 Проект — призёр научно-практической конференции
> «Инженеры будущего» (направление IT-вертикаль).

---

## 💡 Проблема и решение

Официальные клиенты перегружены графикой и требуют стабильного
интернета. На переменах, когда сеть в школе перегружена, загрузка
дневника занимает десятки секунд.

**Решение:** бот запрашивает данные, отбрасывает всё лишнее и отдаёт
ученику чистый текст. Вся обработка — на сервере, телефон получает
только готовый результат.

## 📊 Результаты

| Критерий | Официальное приложение | Бот | Выигрыш |
|---|---|---|---|
| Объём трафика | ~3000 КБ | ~5 КБ | в 600 раз |
| Время отклика | 30–60 сек | 1–3 сек | в 20 раз |
| Действий до цели | 3–7 нажатий | 1 нажатие | мгновенно |

## ✨ Возможности

- **📍 Следующий урок** — предмет и кабинет одним нажатием
- **❗ Мои долги** — автоматический сбор оценок «2», «2 с точкой»
  и пропусков «НВ» в единый список

## 🛠 Технологии

- **Python** — основная логика
- **aiogram** — асинхронный фреймворк для Telegram-ботов
- **REST API + JSON** — получение и парсинг данных
- **Реверс-инжиниринг** — структура недокументированного API
  восстановлена через анализ сетевого трафика (DevTools);
  изучены HTTP-заголовки и механизмы защиты от автоматизации

## 🏗 Архитектура

Логика работы отделена от Telegram — это позволяет перенести бота
на другую платформу без переписывания основного кода.

Пользователь → Telegram → Бот (Python) → API → JSON
→ фильтрация данных → текстовый ответ пользователю


## ⚠️ О демо-версии (важно)

Это **образовательный исследовательский проект**. Чтобы не публиковать
рабочий доступ к стороннему сервису и не обрабатывать чужие
персональные данные, в открытую версию внесены изменения:

- функция `get_mesh_data()` заменена на **mock** — возвращает
  пример JSON той же структуры, что и реальный сервер;
- **рабочие эндпоинты API и механизм авторизации не включены**;
- токен читается из переменной окружения (`.env`), в репозитории
  его нет.

Благодаря этому бот **полностью запускается и демонстрирует логику**
(парсинг, фильтрацию, интерфейс) на безопасных демо-данных.

## ▶️ Запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/zara-engine/mesh-impulse-bot.git
cd mesh-impulse-bot

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Создать .env по образцу и вписать токен бота
cp .env.example .env
# затем открыть .env и указать BOT_TOKEN

# 4. Запустить
python bot.py
